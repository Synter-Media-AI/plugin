# Write-capable outbound skills

These skills (`outbound`, `outbound-research`, `outbound-replies`) instruct
write/send MCP tools (for example `update_pending_approval` to approve or reject pending
outbound drafts and prospect replies, and `synter_audience` to build or export audiences). They are kept here so the source is not deleted, but they
are **not** part of the free read-only Cursor Marketplace listing or the Claude
directory package.

Do not move them back under `skills/` without a review of the read-only
allowlists and CI guards.
