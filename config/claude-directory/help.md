# Synter help

This plugin connects to Synter's hosted advertising service over OAuth. Use **quickstart** to sign in and **connect** to verify accounts.

Use **report** and **attribution** to review performance, **media-plan** to review campaign plans, and **audience** to inspect targeting. Read [brand and safety guidance](../../context/brand-and-safety.md) before using account data.

This directory package uses static instructions and the declared remote MCP connection. Account lookups and reports run through Synter MCP tools. Use only tools in the bundled [tool directory](../../tools/directory-tools.json) and the live server schema; report unavailable capabilities plainly. Confirm the workspace and account, and verify results against the returned tool data before claiming completion.
