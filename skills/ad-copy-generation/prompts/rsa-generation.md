# RSA Generation Prompts & Best Practices

## Headline vs Description Guidelines

### Headlines (30 chars max)
- **Purpose**: Grab attention, include keywords, create curiosity
- **Structure**: Short, punchy, action-oriented
- **Keywords**: Include primary keyword in 3+ headlines
- **Variety**: Mix keyword-focused, benefit-focused, and CTA headlines

### Descriptions (90 chars max)
- **Purpose**: Expand on value, provide details, drive action
- **Structure**: Complete sentences with clear CTA
- **Content**: Features, benefits, social proof, urgency

## High-Performing Copy Patterns

### Patterns That Convert

1. **Numbers & Statistics**
   - "50% Off Today Only"
   - "10,000+ Happy Customers"
   - "In Stock - Ships in 24 Hrs"

2. **Urgency & Scarcity**
   - "Limited Time Offer"
   - "Only 5 Left in Stock"
   - "Sale Ends Tonight"

3. **Social Proof**
   - "Rated 4.9/5 Stars"
   - "Trusted Since 2010"
   - "As Seen On [Publication]"

4. **Risk Reduction**
   - "Free Returns"
   - "Money-Back Guarantee"
   - "No Contract Required"

5. **Direct Benefits**
   - "Save 3 Hours/Week"
   - "Boost Sales 40%"
   - "Cut Costs in Half"

### Power Words for Headlines
```
Free, New, Save, Get, Try, Discover, Proven, 
Guaranteed, Easy, Fast, Now, Today, Exclusive
```

### CTA Phrases for Descriptions
```
Shop Now, Get Started, Learn More, Try Free,
Request Quote, Book Today, Contact Us, See Plans,
Compare Options, Download Now, Sign Up Free
```

## Pinning Strategy

Only pin when absolutely necessary:
- **Pin Position 1**: Brand name or primary keyword headline
- **Pin Position 2**: Key differentiator or offer
- **Never pin**: CTAs or generic headlines

## A/B Testing Framework

### Test One Element at a Time
1. **Offer focus**: Discount % vs Free shipping vs Bundle deal
2. **Urgency**: With deadline vs Without deadline
3. **Proof**: Customer count vs Years in business vs Rating
4. **CTA**: Action verb vs Question vs Statement

### Minimum Test Duration
- 2 weeks or 1,000 impressions per variant
- Statistical significance: 95% confidence minimum
